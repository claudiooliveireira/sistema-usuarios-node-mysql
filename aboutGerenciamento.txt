SEMPRE tem que usar o WHERE em UPDATE e DELETE, WHERE id = ?;

Se esquecer o WHERE no DELETE, o o banco apaga todos os usuários de uma vez;

Se esquecer no UPDATE, ele muda o e-mail de todo mundo para o mesmo endereço;

PS: Sempre conferi o WHERE  duas vezes vezes antes de rodar!

SET: para definir qual coluna;
WHERE: diz qual linha ver ser mudada;

Ciclo CRUD
Create - INSERT =  Para colocar dados.
Read - SELECT  = Para buscar e ver os dados ( no Node e no Workbench).
Updata - UPDATE = Para modificar um registro existente.
Delete - DELETE = Para deletar e precisa do WHERE para não apagar tudo.
