inicio
inicia o projeto node ( gera o package.json) => 
npm init -y           -> no terminal 

instala o drive para o node falar com o mySQL
npm install mysql2





== Express 
Usar o Express Framework do node.js. Ele vai permitir o código MySQL responda as requisições do navegador.

instalar o Express
npm install express  -> no terminal

"Arquitetura"
db.js: Só cuida da conexão com o MySQL ( Bench ).
app.js: É o servidor que cria as rotas (URLs).
